# 카드뉴스·대본 스튜디오 (Card News Studio) — Premium

긴 글을 **카드뉴스 PNG**로 나눠 뽑고, 같은 주제로 **30초 숏폼 대본과 `.srt` 자막**까지 만드는
브라우저 전용 스튜디오. 여기에 **마케팅 심리학 엔진**과 **핀터레스트 디자인 DNA 엔진**, 그리고
**내 구독 AI(ChatGPT·Claude·Gemini) 원클릭 브리지**를 얹었습니다.

화면은 **A안 Crisp Bento**(순백 서피스 · 1px 라인 · 코발트 단일 액센트)로 통일했습니다.

서버·빌드·외부 트래커 없이 정적 파일만으로 동작하고, 작업 내용은 이 브라우저 `localStorage`에만 저장됩니다.

- 미리보기: `preview-v2.png` (디자인 스튜디오 v2) · `preview-v2-mobile.png` · `preview-upgraded.png` · `preview-desktop.png` · `preview-script.png` · `preview-bridge.png` · `preview-mobile.png` · `preview-pro.png`
- **디자인 시스템(A안)**: `#FAFAFA` 바탕 / `#FFFFFF` 카드 · 1px `#E7E8EA` 보더 · 16px 카드 라운드 · 잉크 `#0C0D0F` · 코발트 `#2F5BFF` 단일 액센트. 본문 텍스트 대비는 실측 **4.62:1 ~ 19.44:1**(AA 통과), 포커스 링 5.17:1. 다크 모드는 같은 구조의 잉크 테마.
- **Pro AI 연결(선택)**: 헤더의 `무료 모드 · API 연결` 배지에서 OpenAI·Gemini·Claude·자체 서버를 연결하면, 카드 분할·숏폼 대본 탭의 **✨ Pro AI로 8장 카드+30초 대본 생성**이 슬라이드 8장과 4비트 대본·자막을 한 번에 채웁니다. 연결하지 않으면 붙여넣은 글의 자동 분할과 무료 대본 엔진이 그대로 동작합니다. 키는 기본 `sessionStorage`. 엔진: `engines/pro-api-connector.js` · `engines/pro-studio.js`
- 같은 패밀리: `../shortform-radar/` (떡상 레이더) — IBM Plex Sans KR, 라이트/다크 토글, 빌드 없는 HTML/CSS/JS

화면과 파일이 픽셀 단위로 같습니다.

## 2. AI 추천 레이아웃 & 스타일 (핀터레스트 DNA)

**"추천 받기"** 를 누르면 현재 슬라이드 글 전체(제목·본문, 대본 입력 포함)를 디자인 엔진이 분석해
**핀터레스트 스타일 3~4안을 이유와 함께** 카드로 보여줍니다. 하나를 누르면 색·레이아웃 구도·타이포·
그래픽이 즉시 캔버스에 적용됩니다.

| # | 프리셋 | 구조 | 한 줄 성격 |
|---|---|---|---|
| ① | 스위스 타이포 매거진 | `swiss-grid` | 12열 격자, 좌 텍스트·우 이미지, 큰 섹션 번호 |
| ② | 벤토 그리드 SaaS | `bento-modular` | 둥근 카드 2장 + 알약 배지 |
| ③ | 크림 에디토리얼 | `split-editorial` | 좌 55% 이미지·우 텍스트, 홀수 장은 좌우 반전 |
| ④ | 다크 네온 임팩트 | `full-bleed-photo` | 풀블리드 사진 + 하단 스크림 + 네온 룰 |
| ⑤ | 커머스 클린 화이트 | `product-stack` | 1:1 상품 컷 → 제목·본문 → 하단 CTA |
| ⑥ | 네오 브루탈리즘 | `brutal-block` | 3px 테두리 + 6px 하드 섀도 + 스티커 |
| ⑦ | 미니멀 럭셔리 세리프 | `minimal-poster` | 중앙 정렬, 세리프, 와이드 자간 |
| ⑧ | 비비드 팝 카드 | `pop-stack` | 큰 라운딩 카드 + 숫자 스티커 |

- 추천은 업종 적합도 0.30 · 목적 0.18 · 무드 0.14 · 밀도 0.12 · 신뢰 0.10 · 차별성 0.10 · 접근성 0.06에
  프리미엄·긴급·구매 의도 가산과 **AI 기본값(보라·파랑 + 큰 라운딩 + 소프트 섀도) 감점**을 더해 점수를 냅니다.
- 카드에는 **적합도 %**, **이유**(예: "푸드·리빙 적합도 95%", "AI 기본값 위험 → 감점"), **주의**가 함께 나옵니다.
- 적용 중인 스타일은 `해제`로 기본 테마로 돌아갑니다. 테마 6종 버튼을 누르면 자동으로 해제됩니다.

### 실사 사진

`실사 사진 넣기`로 JPG/PNG를 올리면 1280px·JPEG로 줄여 `data:image/jpeg`로 보관하고,
선택한 스타일의 이미지 존(또는 풀블리드)에 **cover 크롭 + 포커스 + 오버레이(스크림)** 로 배치합니다.
사진이 없을 때는 회색 박스 대신 프리셋별 **그래픽 블록**(제품 실루엣·모듈 카드·격자·세리프 인용 등)을 그립니다.
서버로는 전송되지 않습니다.

### 레퍼런스 이미지 → 팔레트

`레퍼런스 색 추출`(또는 화면에서 **Ctrl+V**)로 이미지를 넣으면 픽셀을 5bit 양자화해
배경·서피스·포인트·잉크를 뽑고, WCAG 4.5:1을 넘도록 보정한 뒤 **카드 색으로 즉시 적용**합니다.
적용 중에는 프리셋의 구조·타이포는 두고 색만 바뀝니다(구도는 프리셋, 색은 레퍼런스).
`색 해제`로 원래 팔레트로 돌아갑니다.

## 3. 카피 진단 · 프레임워크 (마케팅 심리학)

### 8대 트리거 진단

선택한 슬라이드(또는 대본 전체)를 8개 트리거로 채점합니다 — 손실회피 15 · 구체숫자 15 ·
호기심갭 12 · 인지반전 10 · 사회적증거 13 · 희소성 12 · 권위 13 · 저마찰 CTA 10 (가중 합 100).

- **점수 0~100 + 등급 S/A/B/C/D + 개선 제안 1순위**(예: "사회적 증거 20→50점: 후기 1,842건·평점 4.8처럼 셀 수 있게")
- 카드 탭 인스펙터와 대본 탭에 미니 바 8개, **프레임워크 변환** 모달에는 트리거별 채점 이유·고치는 법이 나옵니다.

### 추상어·공급자어 자동 교정

`추상어 교정` 버튼은 **의미를 바꾸지 않는 교정만** 자동 적용합니다.

- 적용: `매우/정말로/굉장히/너무나/아주` 삭제, `저희는/당사는` 같은 공급자 주어 삭제,
  `되어집니다 → 됩니다` 이중 피동, 공백 정리.
- **적용하지 않고 제안만**: "저희는 …을 제공합니다" → "지금 바로 받아보세요"처럼 **문장을 통째로 CTA로
  바꾸는 제안**. 사용자의 문장을 지우는 대신, 모달의 감점 표현 목록에 이유·대안과 함께 남깁니다.
- 교정 전후 감점 점수를 토스트로 보여줍니다(예: `감점 36 → 0`).

### PAS · BAB · AIDA · 4U 원클릭 변환

현재 카드에서 제품·타겟·문제·해결·증거·기한·CTA를 자동으로 뽑아 입력칸에 채우고,
프레임워크를 고르면 헤드라인과 3~4단 카피를 만듭니다.

- **슬라이드에 반영** → 표지 + 본문(섹션별) + 마무리로 재구성(최대 8장).
- **대본에 반영** → 0~3 / 3~12 / 12~25 / 25~30초 4구간 대본·자막으로 재구성.
- 생성된 카피 자체 점수도 함께 보여줍니다.

## 4. 내 구독 AI 원클릭 브리지

API 요금 없이 **이미 쓰는 ChatGPT Plus / Claude Pro / Gemini 무료**를 그대로 쓰는 기능입니다.

1. 만들 것(카드뉴스 세트 · 30초 대본 · 카피 개선안)을 고릅니다.
2. **ChatGPT / Claude / Gemini** 버튼을 누릅니다 → 완성된 프롬프트가 **클립보드에 복사**되고
   해당 AI가 **새 창**에 열립니다(로그인된 구독 계정 그대로).
3. 열린 창에 붙여넣고(Ctrl+V) 답변을 오른쪽 **"AI 답변 붙여넣기"** 에 붙여넣습니다.
4. 답변을 자동으로 읽어 **미리보기**를 보여주고, `적용`을 누르면 슬라이드/대본이 바로 바뀝니다.

프롬프트에는 내 콘텐츠, 지켜야 할 규칙(한 장 한 가지, 34/90자, 구어체, 숫자 날조 금지, `**강조**`,
8대 트리거 4개 이상)과 **JSON 출력 스키마**가 들어 있어 파싱이 안정적입니다.
JSON이 설명과 섞여 있거나, 코드블록·쉼표 오류·번호 목록·"0~3초:" 같은 산문이어도 읽습니다.

### 무료 Gemini API 키 (선택)

Google AI Studio에서 만든 무료 키를 넣으면 복사·붙여넣기 없이 이 화면에서 바로 생성합니다.

- 키는 `localStorage(cns.v1.gemini)`에만 저장되고 **Google 생성 API 외에는 전송되지 않습니다.**
- `키 확인`은 `models` 목록을 조회해 사용 가능한 `generateContent` 모델을 select에 채웁니다
  (기본 `gemini-2.5-flash`). 무료 한도를 넘으면 결제가 아니라 `429` 안내만 뜹니다.
- 키는 카드·대본·프리셋·내보내기 파일에 절대 포함되지 않습니다(단위 테스트로 검사).
- 키 없이도 복사·붙여넣기 방식은 그대로 동작합니다.

## 5. 디자인 스튜디오 v2 — 사진 한 장으로 같은 구도

디자인 엔진 2.0.0을 이 앱에 얹었습니다. 좌측에서 세트 맥락(업종·무드·밀도)을 분석하고,
우측에서 실제 카드 4~7장을 같은 키트로 미리 그립니다.

| 도구 | 하는 일 |
|---|---|
| **① 레퍼런스 1클릭 검색** | 업종·무드·글자 밀도로 검색어를 만들어 핀터레스트·비핸스를 새 창으로 엽니다(누를 때만). |
| **② 폰트 믹스 6종 · 종이 질감 4종** | 명조 제목/고딕 본문, IBM Plex, 라운드 팝 등과 필름 2%·종이 3%·신문지 4.5%를 즉시 비교합니다. |
| **③ 브랜드 키트 고정** | 색·폰트·질감·구도를 이름으로 저장(localStorage)하고 다음 편에 그대로 재적용합니다. JSON 복사·붙여넣기 지원. |
| **사진 해부 → 90% 복제** | 구독 AI에 사진 1장과 함께 붙여넣을 프롬프트를 복사하고, 받은 블루프린트 JSON으로 카드 세트 전체를 같은 구도로 다시 그립니다. |
| **세트 밀도 경고** | 한 장 25자를 넘는 카드를 짚어 "본문 42자 → 14자 한 문장"처럼 줄일 곳을 알려 줍니다. |
| **현재 카드 PNG** | 블루프린트의 캔버스 명령으로 선택한 카드를 1080×1350 PNG로 저장합니다. |

카드뉴스 탭의 테마·AI 추천 레이아웃은 그대로 동작하며, v2 미리보기는 구도·폰트·질감 검증용입니다.

## 개인정보

입력한 글·사진은 브라우저 밖으로 나가지 않습니다. 네트워크는 **사용자가 직접 누른 경우에만** 발생합니다:
프롬프트 복사 후 AI 사이트 새 창 열기(ChatGPT·Claude·Gemini), 그리고 Gemini 키를 저장하고
`키 확인`/`Gemini로 생성`을 누를 때 Google 생성 API 호출뿐입니다. 자동 요청·트래커·외부 스크립트는 없습니다.
