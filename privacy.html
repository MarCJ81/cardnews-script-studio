개인정보 처리 방침

카드뉴스·대본 스튜디오 · 최종 갱신 2026-11-21

1. 수집하는 개인정보

없습니다. 이 앱은 회원가입·로그인·결제가 없고, 서버로 전송되는 데이터가 없습니다. 입력한 카드 문구, 대본, 브랜드 키트, 프리셋, 설정은 모두 사용자의 브라우저 localStorage에만 저장됩니다.

2. 사진

사진 넣기 기능으로 올린 이미지는 브라우저 안에서만 1280px JPEG로 줄여 보관되며, 프리셋에는 저장되지 않습니다. 사진이 외부로 업로드되는 일은 없고, 내려받은 PNG·ZIP에만 포함됩니다.

3. 외부 전송

앱을 여는 것만으로는 외부 요청이 0건입니다. 폰트·스크립트·이미지가 모두 이 폴더 안에 있습니다. 사용자가 'ChatGPT 열기·Claude 열기·Gemini 열기' 버튼을 누를 때만 해당 사이트가 새 창으로 열리고 프롬프트는 이 브라우저의 클립보드에 복사됩니다. 무료 Gemini API 키를 저장한 경우 키는 이 브라우저의 localStorage(cns.v1.gemini)에만 남고, 'Gemini로 생성'을 누를 때만 Google 생성 API로 프롬프트와 함께 전송됩니다.

Pro API 연결(선택). 'Pro AI로 8장 카드+30초 대본 생성'을 쓸 때만, 주제·타깃·포인트·붙여넣은 글 등 입력한 내용이 사용자가 고른 제공자(OpenAI·Google Gemini·Anthropic Claude 또는 직접 입력한 자체 서버)로 브라우저에서 직접 전송됩니다. 연결하지 않으면 전송은 없습니다. API 키는 기본적으로 sessionStorage(탭을 닫으면 삭제)에만 두고, '이 브라우저에 기억'을 켰을 때만 localStorage에 남습니다. 키는 요청 헤더로만 나가며 화면·주소·오류 문구에 남기지 않습니다. '연결 해제'를 누르면 저장된 키가 지워집니다.

4. 쿠키·추적

쿠키를 쓰지 않고, 분석 도구·광고 픽셀을 넣지 않습니다. 다른 사이트로 보내는 추적 신호도 없습니다.

5. 내보내기

PNG·ZIP·SRT 파일은 사용자가 버튼을 눌렀을 때 브라우저가 직접 만들어 내려받는 방식이며, 어디에도 업로드되지 않습니다.

6. 보관과 삭제

모든 작업 내용은 브라우저 저장소를 지우면 함께 삭제됩니다. 앱 안에서 프리셋을 개별 삭제할 수 있고, 저장한 Gemini 키도 앱에서 지울 수 있습니다.

7. 제3자 제공

제3자에게 제공하는 데이터가 없습니다. AI 브리지나 Gemini를 직접 실행한 경우, 해당 요청은 사용자가 고른 서비스로만 갑니다.

8. 문의

이 앱은 정적 파일로 배포되며, 운영자에게 개인정보가 전달되지 않습니다. 문의는 앱을 전달한 채널로 남겨 주세요.
